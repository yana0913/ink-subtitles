# 墨迹 · 手写字幕工坊

保留真实手写笔迹，从多张歌词照片逐行导出透明 PNG。纯静态网站，没有外部依赖，照片仅在浏览器内处理。不是文字 OCR，不生成 SRT 或自动对齐音频。

## 使用

1. 用深色笔在干净白纸上写歌词，每句独立一行，留出足够行距，正面拍摄。
2. 上传多张 JPG / PNG / WebP。每张最多 25 MB，图片最长边会缩放到 2400 像素。
3. 调整去底强度和分行间距，点击“提取全部照片”。
4. 分行不准时，在照片上拖动框选每句，再次提取。使用框选后只提取框选区域；可撤销或恢复自动分行。
5. 选择白色、黑色、暖橙或保留原色；选择紧贴文字或 1920 × 1080 底部居中画布。
6. 检查预览，移除不需要的片段，逐张下载或下载 ZIP。拖进剪辑软件后设置每句出现的时间和时长。

照片顺序按上传顺序，手动框选按从上到下顺序。重新上传或调整参数会清空导出预览；原照片保留在当前页面内存中，刷新后清空。


## 适用范围

适合浅色无格线纸张上的深色文字。自动分行依赖横向留白；阴影、格线、倾斜拍摄、背景杂物和彼此相连的行可能需要调整参数或手动框选。浅色笔迹建议重拍或提高去底强度。当前没有透视矫正或复杂背景抠图，PNG 没有时间轴。

## 验证

已验证 JavaScript 语法、纯白背景透明化、两行笔迹分割、边界裁剪、空白图以及 ZIP 完整性和中文文件名。浏览器中示例生成三张 PNG，ZIP 下载成功。示例使用字体模拟；真实手写照片效果仍需用你的照片确认。
